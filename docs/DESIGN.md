# 南方散步 — DESIGN v2

版本：v2  
適用頁面：散步首頁、行程管理、3D 旅程與分享頁  
設計代號：**南境手札**

## 設計目標

南方散步是 Aya 的雪梨與塔斯馬尼亞 25 天旅程，主要在手機上私人使用。首頁以每日路線為主角：使用者向下捲動，小人走過景點，景色從身旁經過。

設計保留手繪線稿、紙色與朱紅識別，並以穩定的文字層級、清楚的觸控回饋和可中斷的動態，讓旅程資訊容易閱讀與操作。

## 設計理念

### 從 weya ESG 頁面採用

- 捲動代表向前行進；小人固定在畫面下方，場景和路線從身旁經過。
- 一個畫面先傳達一個重點。每天有短標題，時間、交通方式和站點名稱作次級資訊。
- 每天是一個章節，以日期、日序和地區辨識。
- 遠景降低細節，近景景點清楚呈現。
- 首屏以短句和捲動提示邀請使用者開始散步；完整行程內容仍由 `/plan` 提供。

### 結合 Apple 設計原則

- 觸控捲動與畫面位置保持 1:1；不在手勢相關動態上加入延遲。
- 動態從目前畫面值開始，使用者可以隨時反向或中斷。
- 滑鼠滾輪以臨界阻尼彈簧平滑小段落差；觸控捲動與觸控板保持原生回饋。
- 浮層從觸發點出現，也沿原路返回。
- 半透明材質只用於導覽和日期列；偏好減少透明度時切換為實色。
- 字級使用 `rem`，觸控目標至少 44px，必要資訊不只靠顏色傳達。

### 視覺取捨

- 近景景點、路線和角色維持手繪線稿。
- 遠景保留線稿，可用一層極淡平塗增加景深；平塗透明度不超過 `0.35`。
- 使用低彩度章節底色，不使用大面積飽和色塊。
- 介面文字、導覽與控制維持清晰規整，不套用手抖濾鏡。
- 3D 旅程維持深色場景，與紙色頁面之間的明暗變化是本版已知差異。

- 膠囊圓角：`999px`。
- 一般插畫線稿：`1.6px`，圓頭、圓角。
- 路線底線：`1.4px`；走過路線：`2.6px`。
- 地區時間軸：`1.5px` 實線或點線。
- 線條圖示：`1.5px`，常用尺寸 `20×20px` 或 `24×24px`。
- 焦點外框：`3px solid`。

### 材質與紙紋

- 紙紋只保留一層，透明度 `0.05`，作為背景圖樣放在內容後方。
- 不在整個視窗上固定覆蓋紙紋，不使用 multiply 疊在文字和控制上。
- 頂部共用導覽高度 `56px`，加上 `env(safe-area-inset-top)`。
- 底部日期列高度 `64px`，加上 `env(safe-area-inset-bottom)`；主要內容底部至少留 `80px + safe-area-inset-bottom`。
- 紙色頁面的導覽使用 `rgba(250,247,240,.88)`、`backdrop-filter: blur(14px)`。
- 一個介面位置只疊一層半透明材質，不在半透明面板上再疊半透明按鈕。
- `/journey` 使用同一導覽尺寸與結構，但採深色玻璃背景 `rgba(11,20,24,.88)`、模糊 `14px`，確保文字在 3D 場景上可讀。

## 首頁散步

### 首屏與章節

- 第一屏直接呈現第一天的路線、角色、日期及短標題：「跟著 Aya，走過南方的每一天。」
- 標題字級 `32–56px`，不使用不可換行的整句文字；縮放後允許自然換行。
- 捲動提示為膠囊形控制，高度至少 `44px`。
- 每天顯示日序、日期、每日標題與地區；當前日序和地區標籤固定在導覽可視範圍。
- 雪梨日使用 `#FBF5EE`，塔州日使用 `#F3F6F1`。相鄰日切換時背景 `300ms` 交叉淡化；減少動態偏好時直接切換。

### 角色位置與路線

- 每日舞台高度為 `100svh`，使用舞台實際尺寸計算路線，不以 `innerHeight` 代替舞台高度。
- 桌面角色腳底錨點：`x = 40vw`。
- 手機角色腳底錨點：`x = 34vw`。
- y 座標使用：

  `yFoot = min(0.72 × stageHeight, stageHeight − bottomBarHeight − safeAreaBottom − 24px)`

  其中日期列內容高度為 `64px`。角色在一般捲動範圍內維持上述錨點；路線起訖端各自預留足夠空間，避免相機碰到邊界後角色偏離錨點。

- 垂直捲動進度直接映射路線進度：

  `p = clamp((shownScrollY − dayTop) / (dayHeight − stageHeight), 0, 1)`

  不對觸控捲動的 `p` 加 easing。路線、遠景、小人與腿部步伐皆由同一進度值計算；停止捲動時動態停止，反向捲動時畫面立即反向。

- 手機路線點位間距：`max(260px, 0.78 × viewportWidth)`；第一個點位 x 座標為 `0.78 × viewportWidth`。
- 桌面路線點位間距：`clamp(340px, 0.36 × viewportWidth, 480px)`；第一個點位 x 座標為 `0.62 × viewportWidth`。
- 路線尾端預留 `viewportWidth − anchorX + 24px`，起點預留至少 `anchorX + 24px`，確保小人不因起訖邊界離開錨點。
- 路線曲線以圓滑貝茲曲線連接站點；遠景以 `0.5×` 速度移動，靜態遠景透明度 `0.5`。
- 角色步伐依路線距離推進，每 `10px` 路徑更新一次步伐相位；停下時腿部姿勢固定。
- 交通工具依站點間交通資料切換：步行、開車、公車、火車、渡輪、飛機各有獨立圖示。交通方式不從景點種類推測。

### 站點到達、互動與速度

- 站點插畫在角色接近時依捲動進度描線；倒著捲可中斷與反向。
- 站點距離角色 `36px` 內時顯示景點名稱；站點暈色在插畫描線進度超過 `0.6` 時出現。
- 站點到達文字、暈色與線稿的顯示均由目前捲動位置決定，不使用固定時長 transition。
- 點選站點可前往該站對應的捲動位置。站點需能以鍵盤操作，提供可見焦點；啟動方式為 Enter 或 Space。
- 到站只代表散步頁的示意進度，不代表 GPS 定位或實際到訪。
- 原生觸控捲動保持 1:1，放手後由瀏覽器原生慣性與 proximity snap 決定停止位置。
- 螢幕閱讀器以獨立 `#rw-live` 狀態區播報換日；視覺日期列本身不設 `aria-live`，避免連續捲動造成重複播報。
- 每日進度條以 `transform: scaleX()` 更新，不逐格改寬度。
- 日期列只包含前一天、目前日、日期選單、全程進度線和「查看當日行程」，不加入 25 日水平滑動列。

### 換日與鍵盤

- 底部前後日按鈕最小 `44×44px`；按下時即時縮放至 `0.94`，回復時間 `100ms`。
- 近距離換日使用臨界阻尼彈簧，從當前畫面值與速度開始，可被新捲動、按鍵或點選中斷。
- 跳到相隔兩天以上時，散步舞台 `140ms` 淡出、立即定位、`140ms` 淡入；新的輸入會取消尚未完成的瞬移計時器。
- 手機在站點附近使用垂直 `scroll-snap-type: y proximity`；吸附點位於景點對應的捲動位置。
- Scroll snap 只套用在散步頁，不影響 `/plan` 或 `/journey`。
- `←` / `→` 前往上一個／下一個景點；`[` / `]` 前往前一天／後一天。
- 第一日與最後一日保留文件捲動容器的原生邊界回饋；根文件不使用 `overscroll-behavior: none`。

### 目前已套用的 Apple 流暢度 patch

- 動態朱紅路線已移出 `feTurbulence` 濾鏡群組；濾鏡只套用靜態墨線。
- 路線點位、站點位置與每日區段幾何在 layout 時計算並快取；捲動影格不讀取 `offsetTop` 或 `offsetHeight`。
- DOM 採差異寫入；只有值變更時才更新站點狀態、圖示與文字。
- 進度線改用 `scaleX()`，更新 transform。
- 桌面離散滾輪位移使用臨界阻尼彈簧，`response = 0.20s`，從目前畫面值追向新目標並可重新指定目標。
- 觸控捲動維持原生 1:1。
- 站點可點選並捲動到該站；鍵盤方向鍵走站點，`[` / `]` 換日。
- 手機站點附近使用 `scroll-snap-type: y proximity`。
- 底部按鈕高度至少 `44px`，按下縮放 `0.94`。
- `#rw-live` 只在日期改變時播報。
- 頂部導覽下方有暖紙色漸層，讓內容滑過時仍保有文字對比。

實作對齊規則：目前程式以 `(pointer:fine)` 判斷是否套用 0.20 秒彈簧，這會涵蓋部分觸控板操作。最終行為限定為離散滑鼠滾輪事件；觸控與觸控板保持 1:1。

## 導覽與定位

### 共用導覽

所有頁面使用相同順序與文字：

1. 標誌「南方散步」：回到目前資料範圍的散步首頁。
2. 「散步」：`/` 或分享首頁 `/s/{token}`。
3. 「行程」：`/plan` 或分享行程 `/s/{token}/plan`。
4. 「3D」：`/journey` 或分享 3D 頁 `/s/{token}/journey`。
5. 登入或登出：依登入狀態與目前權限顯示。

目前頁使用 `aria-current="page"`。導覽固定於頂部安全區內；手機仍顯示可辨識的文字標籤，每個入口高度至少 `44px`。預算是行程分頁，不列入主導覽。

### URL 規則

| 用途 | 擁有者／公開首頁 | 分享頁 |
|---|---|---|
| 散步首頁 | `/` | `/s/{token}` |
| 行程總覽 | `/plan` | `/s/{token}/plan` |
| 每日行程 | `/plan?tab=days&day=YYYY-MM-DD` | `/s/{token}/plan?tab=days&day=YYYY-MM-DD` |
| 預算 | `/plan?tab=budget` | `/s/{token}/plan?tab=budget` |
| 3D 旅程 | `/journey` | `/s/{token}/journey` |

散步頁每日錨點格式為 `#rw-day-YYYY-MM-DD`，所有日期包含第一天均使用一致格式。從行程頁回到散步時保留日期，例如 `/#rw-day-2026-11-03` 或 `/s/{token}#rw-day-2026-11-03`。

分享頁的頁面切換必須保留 `{token}`。在散步頁點選「查看當日行程」時，導向對應的 `tab=days` 與日期；在 `/plan` 切換分頁或日期時，URL 同步更新。

### `/plan` 預設位置

- 以 `Australia/Hobart` 當地日期判定是否在旅程期間。
- 旅程日期 `2026-11-03` 至 `2026-11-27` 含首尾日；期間內首次開啟預設 `tab=days`，選中今天。
- 期間外預設 `tab=overview`。
- URL 中明確指定 `tab` 或 `day` 時，以 URL 優先。
- 今日不在行程日期列表中時，期間內預設選擇下一個未來行程日；沒有未來日期時選最後一日。

## `/plan` 版面規則

### 頁面結構

- 使用共用 header，頁面標題下方顯示行程日期、25 天總長、目前模式（擁有者／唯讀分享）與同步狀態。
- 局部分頁保留：總覽、每日行程、地圖、預算、待安排景點、資訊與警示、版本與分享。
- 分頁列手機可水平捲動；右緣顯示淡出遮罩提示尚有內容，保留至少一個下一分頁的部分可見區；選取分頁自動捲入視野。
- 分頁高度至少 `48px`，具備 `tablist`、`tab`、`tabpanel` 對應 ID、`aria-controls` 和左右鍵操作。
- 離線、唯讀、擁有者狀態以文字標明，不只用色塊表示。

### 每日行程

2026-10-23 依 UI-REVIEW-LOG 精簡：
- **當天標題區**：有照片時放 `168px` 首圖（第一個有照片的主要活動）。只常駐提醒和司機狀態兩種徽章，下面兩格（當日花費、今晚住宿）；其餘收進「當日摘要」。
- **活動卡**：主線只放時間、名稱，必去或暫定時才加一個徽章；第二行是交通方式和金額；照片縮圖 `104×78`（桌面 `144×108`）。
- **活動備註**：一般備註先顯示兩行，按「更多」展開；含 ⚠ 的備註一律完整顯示並加底色。
- **收合區**：英文名、查核與優先度、來源、費用計算、照片出處、整組行程說明放進「更多資訊」；擁有者的編輯按鈕放進「管理」。
- **預算**：金額依活動計算。沒有活動的日子是 $0，不再自動加每日三餐；餐費要算就加成活動，住宿另計。

- 桌面左側月曆欄寬 `300px`（只在 `721px` 以上）；內容區使用 `minmax(0, 1fr)`，避免固定最小寬度造成水平溢出。
- 日期選擇見下方「月曆」。
- 每日標題依序顯示日序、日期、地區名稱和每日行程標題。
- 主要活動、預估開車、當日預算和住宿以 `paper-raised` 小區塊呈現。
- 活動時間線使用墨色主線；雪梨實線、塔州點線。活動節點與交通文字均有標籤，不只靠顏色和 emoji 表達。
- 手機版地圖排在活動清單之後，地圖高度 `280px`；使用者可收合地圖回到時間線。
- 行程項目需要可掃讀的時間、活動名、交通、停留時間、必要提醒和操作區。
- 重要提醒使用淺底、左側 `2px` 朱紅線與明確文字；成功／中性狀態使用墨色，不增加一套地區綠色。
- 操作按鈕至少 `44×44px`；主要表單控制字級至少 `16px`。
- 版本、預算表和分享網址採同一分組與間距規則；窄螢幕表格允許局部水平捲動，不推動整頁溢出。

### 月曆

2026-10-23 起，「待安排景點」不再是獨立頁籤：`?tab=pool` 會自動轉到 `?tab=map`，頁籤名稱改為「地圖與景點」。整體做法參考 Apple 地圖：以地圖為主，清單跟地圖同步。

- **版面**：
  - 桌面左邊是地圖，右邊是 `360px` 寬的面板。
  - 手機地圖佔滿畫面，清單放在底部面板，有三段高度：收起（露出 `132px`）、一半（`48%`）、全開（離頂部 `6%`）。
  - 拖曳面板頂部超過 `6px` 後才判斷方向，之後 1:1 跟手，並開啟 pointer capture。放手時用投影（`0.998`）挑最近的一段，用臨界阻尼彈簧收尾（response `0.35s`）。超出範圍有橡皮筋阻力，動畫中可以再抓住。
  - 把手按鈕可以點擊切換高度；點選景點時，面板自動拉到一半。
- **圖層與篩選**：
  - 「已排行程」用實心點，「待安排」用空心紅圈加分類小圖示。
  - 可依地區、分類（10 類：自然・健行、海灘・海岸、觀景點、動物、美食・咖啡、市集・購物、城鎮・老街、歷史・博物館、藝術、體驗・活動）篩選，也可以搜尋名稱、英文名、備註和分組。
  - 可勾選「只列出地圖畫面內的景點」。
  - 篩選條件記在網址：`mapLayers`、`mapSeg`、`mapCat`、`place`。
- **聚集**：縮放 11 以下時，畫面上 `44px` 內的待安排景點合成一個數字圓圈，點一下放大。被選取的景點不會被合併。
- **景點卡片**：
  - 內容：照片（只有擁有者和分享連結看得到）、名稱、英文名、分類、分組、備註、「在 Google 地圖開啟」。
  - 擁有者另有「排進哪一天」，預設建議直線距離最近的同地區行程日，並寫出距離。
  - 清單上方的卡片會淡入；關閉按鈕 `44px`。
- **分類**：每個待安排景點都有 `cat`；匯入時自動指定，擁有者可以修改。
- **整組排入**：舊的分組卡片（含「整組排入」）收在面板最下方的「依分組檢視」。
- **無障礙**：
  - 清單本身就是不用地圖也能操作的方式；每一列都是按鈕，有 focus 樣式。
  - 減少動態時面板直接跳到目標高度。
  - 減少透明度時面板改成實色；增加對比時晶片和卡片加墨色框。

### 只給擁有者看的資訊

- 活動可以有 `ownerNote`，例如航班號碼或工作地點。所有公開文件，包括分享連結，都會移除這個欄位（`toPublicDoc`），隱私檢查也會擋下。
- 訪客只會看到一般文字，例如「Aya 飛回東京（21:30 起飛）」「Kai 有工作（18:00–23:00）」。

### 圖示與連結

- UI emoji 改用同一筆觸的線條圖示，常用尺寸 `20×20px`，線寬 `1.5px`。
- 裝飾圖示設 `aria-hidden="true"`；互動圖示按鈕提供可讀文字或 `aria-label`。
- 日期、地點、倒數等純資訊不加連結底線；真正可操作的連結使用清楚的 hover、focus 與按下狀態。
- 分組卡片使用 `paper-raised`、`16px` 圓角、無陰影；主要卡片內距 `16–24px`。
- 紙紋保持在背景，不能蓋到分頁、表格、表單或對話框上。

## `/journey` 差異

- 保留現有深色 3D 場景、章節、WebGL 畫面與內容，不改場景配色或敘事。
- 使用共用 header 的相同結構、尺寸、名稱和目前頁狀態；在深色背景上採深色玻璃樣式。
- 從一般頁面進入時，3D 內容使用 `180ms ease-out` 淡入；減少動態偏好時直接顯示。
- 紙色頁轉入深色 3D 場景的亮度變化是已知差異，v2 以共用導覽和短淡入維持位置連續性，不改 3D 場景本身。
- `/journey` 回到相同資料範圍的行程；分享頁回到 `/s/{token}/plan`。
- 手機章節目錄保持可觸及，不以隱藏所有章節連結作為唯一導覽方式。

## 動態數值

| 情境 | 數值 | 行為 |
|---|---|---|
| 滑鼠滾輪追蹤 | response `0.20s`、阻尼比 `1.0` | 臨界阻尼，無回彈，起點為目前畫面值 |
| 滑鼠彈簧物理值 | mass `1`、stiffness `986.96`、damping `62.83` | 對應角頻率 `ω = 2π / 0.20` |
| 點選站點／近距離跳轉 | mass `1`、stiffness `225`、damping `30` | 阻尼比 `1.0`，response 約 `0.42s`；沿用當下速度並可中斷 |
| 相隔兩日以上跳轉 | 淡出 `140ms`、瞬移 `0ms`、淡入 `140ms` | 新輸入取消未完成的瞬移 |
| 雪梨／塔州章節底色 | `300ms` | 可反向的交叉淡化；減少動態偏好時 `0ms` |
| `/journey` 進場 | `180ms ease-out` | 只淡入頁面，不改 3D 場景 |
| 按鈕按下 | 立即開始，scale `0.94` | 回復 `100ms ease-out` |
| 捲動中的線稿、暈色、標籤 | `0ms` 固定時長 transition | 顯示量完全由目前捲動位置決定 |

## 無障礙

### 減少動態 `prefers-reduced-motion: reduce`

- 停止遠景視差、腿部循環、線稿逐筆繪製與飛行升降。
- 路線、站點插畫與角色使用完整靜態狀態。
- 換日背景直接切換；跨日跳轉直接定位，不使用淡出或彈簧。
- 3D 頁停止進場動畫與章節位移動畫，場景內容仍可閱讀。

### 減少透明度 `prefers-reduced-transparency: reduce`

- header 和日期列改用實色 `#FAF7F0`。
- `/journey` 共用 header 改用實色深底 `#0B1418`。
- 不以降低文字透明度建立層級。

### 增加對比 `prefers-contrast: more`

- 主文字使用 `#181714`，次要文字使用 `#3E3B34`。
- 焦點框維持至少 `3px solid`，並使用高對比色。
- 線型、文字標籤和圖示同時辨識地區、優先級與警示。
- 不只靠低對比紙紋或淡色線條區分操作區。

### 鍵盤與螢幕閱讀器

- 頂部導覽、日期列、站點和行程操作都可用鍵盤到達。
- 站點互動使用語意化按鈕或連結，不以只有 click handler 的 `div` 代替。
- 視覺裝飾 SVG 設為隱藏；必要內容以文字提供。
- 散步頁提供可讀的每日標題、日期和站點順序。
- `#rw-live` 僅在日序切換時播報；日期選單與單站狀態不逐影格更新 live region。
- 保留瀏覽器縮放，不設定 `maximum-scale` 或 `user-scalable=no`。
- 支援 `viewport-fit=cover` 並為固定 header、底部日期列與 dialog 加上安全區 inset。

## 地圖

- 底圖使用 OpenStreetMap 標準圖磚，以 CSS 濾鏡降低彩度、偏紙色；顯示 OpenStreetMap 姓名標示。網站送出 `strict-origin-when-cross-origin` Referer（OSM 使用政策要求），只含網域，不含分享連結路徑。
- 地圖控制（縮放）放在地圖內，不得蓋過頂部導覽與分頁列；按鈕 44×44px。
- 地圖無法載入時，保留「文字版路線」。

## 效能規則

- 任何 scroll frame 都不讀取 `offsetTop`、`offsetHeight`、`getBoundingClientRect()` 或 `getTotalLength()`；幾何只在 layout／resize 時計算。
- 使用 `ResizeObserver` 或一次排程的 resize layout 重新量測；量測完成後才寫入樣式。
- 朱紅動態路線永遠在 turbulence filter 群組外。
- 每影格只更新當前日及必要相鄰日；離開視窗的日不執行站點描線。
- 對 class、SVG attribute 和文字採差異寫入，值沒有改變就不操作 DOM。
- 進度線只更新 `transform: scaleX()`，不逐格修改寬度。
- 只對需要直接變動的 transform 使用 `will-change`；不把每個站點都提升成獨立合成層。
- 紙紋使用一張小型可平鋪靜態圖樣；不在整個頁面上重複執行 `feTurbulence`。
- 字型 fallback 不等待遠端資源；字型載入不得重建所有日程 SVG。
- 60Hz 參考手機上，捲動更新 P95 目標不超過 `16.7ms`，不出現超過 `50ms` 的捲動主執行緒長工作。
