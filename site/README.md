# Aya 的澳洲旅程｜網站原型

依 `../docs/` 的需求文件做出的**靜態可點擊原型**（路線圖第 2 階段「私人行程原型」）。
不需要安裝任何東西：直接用瀏覽器開啟 `index.html`。

> 這不是系統架構的決定。純 HTML/CSS/JS、沒有伺服器，是為了先驗證需求，之後要選哪種架構仍待決定。

## 檔案
- `index.html`：頁面骨架
- `css/styles.css`：樣式（支援手機、深色模式、減少動態）
- `js/data.js`：**行程資料**，要改行程、價格、住宿就改這裡
- `js/app.js`：畫面與規則邏輯

## 已做到的需求
| 需求 | 網站上在哪裡 |
|---|---|
| 每日行程、時間、交通拆分、費用、警示（FR-01、09、11） | 每日行程 |
| 必去／優先／可替換（FR-05） | 每個活動的標籤，擁有者可修改 |
| 司機未確認 → 暫定＋替代方案（FR-10） | 每日行程的警示、「確認司機與時段」按鈕 |
| 每日活動量與開車時數檢查（FR-12） | 規劃檢查提醒 |
| 逐項預算、單位、狀態、人數重算、共乘分攤（FR-13〜17） | 預算、每日「共乘費用分攤」 |
| 來源、查核時間、可行性標籤（FR-18、NFR-05） | 每個活動、資訊與警示 |
| 版本紀錄，還原會建立新版本（FR-07） | 版本與分享 |
| 唯讀分享、隱藏地址與司機、訪客興趣合計、停用連結（FR-21〜23、28） | 版本與分享、以訪客身分預覽 |
| 離線查看＋最後同步時間（FR-24、25） | 頁尾、列印／下載備份 |
| 地圖與動畫，失敗時有文字版（NFR-01、06） | 地圖、每日路線圖 |

## 重要提醒
所有活動、時間與價格皆為**建議草稿與估計值**，尚未向官方來源查核。出發前請逐一確認，並在網站上按「標記已查核」。
